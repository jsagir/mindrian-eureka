# Theo pose and movement note

Theo is a reusable reasoning character, not decoration. The six compact silhouettes use only the face's eyes and bar, with each posture tied to an inquiry state:

- **Curious:** upright bar and close eyes; notice an uncertainty.
- **Skeptical:** angled bar; question an assumption.
- **Contradicted:** bar leans the other way; evidence conflicts with the current account.
- **Searching:** horizontal bar below the eyes; scan the evidence.
- **Recognition:** shifted upright bar and staggered eyes; a relationship becomes visible.
- **Your move:** outlined eyes and bar; hand the decision to the person.

The core motion follows the reference timing: eyes shift in about 220 ms, posture changes in about 380 ms, the evidence reframe takes about 450 ms, then the scene rests. The four story beats are discrepancy → evidence changes focus → earlier work connects → person selects the next direction. The face is always accompanied by plain-language copy so the reasoning remains clear without motion.
