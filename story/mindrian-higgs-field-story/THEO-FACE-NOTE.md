# Theo face system — Higgs-field visual version

Theo is the outside thinker, not a mascot. The film uses the site's canonical square-geometry face SVGs and named pose targets from `website/public/theo-face.js` and `components/home-story/FaceStill.tsx`.

Each scene animates the face from its neutral geometry into a relevant canonical pose: rest → search → found → listening → search → challenge → decision → handover. The changing plane, slash, eyes, and rules indicate how Theo is engaging with the research. Flat square tiles inside the field carry the material, evidence, questions, assumptions, contradictions, decisions, and handover.
