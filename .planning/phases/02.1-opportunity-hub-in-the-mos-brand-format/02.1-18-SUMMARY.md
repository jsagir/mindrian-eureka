# Phase 2.1 Plan 18: Settled 3D stage

**The local 3D map starts at rest, marks synthetic Potential eurekas with yellow spheres and ink shells, and moves only through one camera player after an action.**

## Accomplishments

The stage feature-tests WebGL before loading the approved local UMD file. Loading waits for the graph view to be visible, so dimensions are real and the initial bank does not create an offscreen renderer. The library, drawing or context-loss failure paths share the existing source-linked fallback list. A handled failure logs one fixed message, without exception data or local paths.

Visible records and pairs become separate node/link objects with safe Map indexes. The supplied neighborhood tints, bridge values, widths and full-opacity cobalt links follow the approved contract. Forces warm up for 300 ticks, cooldown is zero, and settled coordinates are fixed. The first visible frame waits for the actual populated graph and updates world transforms before the immediate fit. There is no rotation, particle or node dragging.

Each marked node has a cloned back-face ink shell at scale 1.18. Its persistent label is the source link, with the candidate status beside it. Selected records have a white label. Labels follow camera/control changes and resize without an ambient label loop. Library HTML tooltips are disabled; owned tips insert text only.

Selection, Find, tour, Zoom and Reset use one token-driven camera player. It reads the 760 ms token and cubic-bezier easing, uses one elapsed-time clock, and makes instant moves under reduced motion. Selection shifts into the area uncovered by the specified side panel or sheet. The stage has its required image label and no tabindex; the canvas is not focusable. The Find/list routes and source links remain ordinary controls.

## Deviations from Plan

Tasks 1 and 2 form one working stage implementation commit. The initial view waits to become visible before creating the renderer; this avoids fitting an invisible box. The library's bounding-box method reads mesh world matrices, so the stage explicitly updates those matrices before fitting. Phone captures and a projected-node regression check exposed and verify that correction.

The reading panel covered the selected sphere in the first captures. The camera now accounts for the panel area, and the label layer uses its uncovered width. The source link is the marked title itself, with candidate status beside it, which removes a duplicated ID row and keeps HUB-03 visible.

The pointer test needed position support in the existing driver to clear by clicking a real canvas corner. The CSP decision test needed a fresh pinned-vendor style probe as well as the older baseline probes. Both are small sibling test-harness changes; they preserve the old negative controls.

The harness accepts a boolean reducedMotion option. Initial test strings incorrectly enabled it for both modes; the final cases use the correct boolean and prove both modes. The camera check was changed from an invented 850 ms endpoint to the plan's 1200 ms deadline after a trace showed long software-rendering frame gaps. No model cut-off or motion token changed.
