# Phase 2.1 Plan 11: Opportunity bank

**A responsive ranked bank with honest engine cut-offs, bounded paging, source links and status on every pair.**

## Accomplishments

The bank registers through HubApp, names both engines in words, interleaves each engine's ordinal ranks without merging scores, and pages 25 rows at a time. Native radios filter by engine. A weaker-pairs control appears only when weak rows exist. Cut-offs come from payload settings; an absent floor uses the approved none copy.

Rows carry Proposed and Inferred role treatments, the exact candidate status, both source links with accessible names, titles, four-decimal scores, verbatim readings, applicable data flags and a Read this pair button. Selection marks the row and persists across views. Empty runs show engine notes; filter-empty results offer the approved reset action. Paging and reset keep keyboard focus on an available control.

The responsive grid stacks on phones, uses six columns on tablets and twelve on desktop. Weak rows keep flags on a paper surface so red text never sits on quiet. No threshold or public data changed.
