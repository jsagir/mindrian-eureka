<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command line to filesystem | `--out`, `--source-dir` and RUN_DIR are paths chosen by the caller |
| run folder to hub folder | Hub files contain record text from the collection |
| hub folder to a viewer | The folder may be copied to another computer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-38 | Tampering | `--out` points at a foreign folder and the build replaces it | mitigate | Marker check `is_hub_folder` through `StagedRun(replaceable=...)`; empty folders only otherwise; tests with a foreign folder, a symlink and a parent folder. |
| T-02.1-39 | Tampering | `--out` inside the run or source folder | mitigate | `ensure_out_dir_allowed` for both folders; tests for equal, inside and holding paths. |
| T-02.1-40 | Spoofing | Source file name read as a link scheme | mitigate | Percent-encoding with `safe=""` and a leading dot-slash; test with `a b:c.md` and a `javascript:` name. |
| T-02.1-41 | Information disclosure | Absolute path, user name or time in hub files | mitigate | All paths are relative; the writer test scans every written file for the temp folder, the home folder, the user name and date-time patterns. |
| T-02.1-42 | Information disclosure | Hub folder readable by other users | mitigate | Files 0o600 and folders 0o700 through `StagedRun`; a posix mode test. The file holds record text, so the docs say to copy it deliberately. |
| T-02.1-43 | Elevation of privilege | Network call by the build | mitigate | `no_network` fixture test; the writer imports no network module. |
| T-02.1-44 | Repudiation | Item without label or link reaches the page | mitigate | `verify_payload` runs before any file is written; test with a broken payload. |
| T-02.1-45 | Tampering | A packaged asset was edited after packaging | mitigate | The writer compares each static asset with EXPECTED_STATIC before writing; test with a changed value. |
</threat_model>
