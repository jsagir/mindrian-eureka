# Phase 2.1 Plan 15: Graph routes and diagram

## Accomplishments

The responsive guide names all six marks and both engine types in words, prints the actual engine cut-offs, and keeps the fixed limits on pair meaning. Find uses the shared record search with at most eight named result buttons. Enter runs it and Escape closes results. The tour selects the payload's marked records in stable order and opens the existing panel.

Small collections use an SVG diagram with deterministic neighborhood/ID ordering, dashed cobalt pair chords, thicker crossing chords, tinted circles, measured 13 px IDs with paper halos and 44 px HTML selection targets. Selecting a record rings it and dims other neighborhoods. Label placement avoids circles and other labels using rendered glyph bounds; it waits for visibility and refreshes after font readiness.

Earned collections use the shared Gr12 fallback until Plan 18 fills startStage. Its paged list is inside the stage and keeps each proposed pair's candidate label, actual sources, engine, scores and flags. Empty runs show Gr17/Gr18. The stage has no keyboard tab stop, and the camera buttons stay hidden until the stage hook enables them.

The read-only graphView handle and named Hook contract for plan 18 expose mode, instance and flyTo plus the internal selection, clear, zoom and reset hooks. Graph readiness is emitted once. The required cobalt/no-particles deviation is recorded once in each authored file and in the model rules.
