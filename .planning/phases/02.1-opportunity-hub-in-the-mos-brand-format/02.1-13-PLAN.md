## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-60 | Tampering | Hostile record text in the panel | mitigate | `HubApp.el` and `textContent`; the full-text split uses string slicing only; hostile-run test. |
| T-02.1-61 | Spoofing | Link with a scheme in a source link | mitigate | `HubApp.el` rejects scheme and double-slash `href`; the test asserts every href is relative. |
| T-02.1-62 | Repudiation | A panel without the label or the source link | mitigate | The loop test covers every record and every pair, with a negative case. |
| T-02.1-63 | Denial of service | Panel for a record with a huge text | mitigate | Only the first 600 characters render at once; the rest sits in a closed details element. |
| T-02.1-64 | Information disclosure | Hover opens a panel and reveals data unasked | accept | Nothing is hidden from a person who holds the file; the rule in the book is about access by keyboard, and the test asserts no hover-only path. |
