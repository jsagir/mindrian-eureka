# Phase 2.1 Plan 12: Catalogue

**All records are reachable through a source-linked catalogue with immediate search, combined filters and bounded paging.**

## Accomplishments

The catalogue precomputes lowercase search strings, matches all query tokens without compiling a query regular expression, and sorts IDs by code unit. Source-file and pair-membership filters combine with search and survive view switches. A polite count reflects the actual filtered set. The empty-state action resets the three catalogue filters and returns focus to search.

One table supplies four scoped column headers, ID source links, title buttons, source files and pair counts. It becomes stacked blocks on phones. Pair counts share the ID cell below desktop; only one count is shown. More pages append 50 rows without replacing existing opener controls. Record and pair selections share the core state. Phone block clicks select the record while source links keep their own action.
