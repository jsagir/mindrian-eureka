## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The plan's scan of manifest.json would always fail on a Phase 2 provenance field**
- **Found during:** Task 1
- **Issue:** `manifest.json` holds `tool.engines.wording_and_meaning.reference = "hsi_reference.py"`. The Phase 2 test `test_run_engines.py` asserts this value and `test_run_manifest.py` uses it. The plan says no `.py` name in manifest.json and also says no behavior change except one note sentence.
- **Fix:** The field stays. The label test removes only that one field before it scans the manifest. Every other file and both streams are scanned whole.
- **Files modified:** tests/test_run_labels.py
- **Commit:** 2cbe4ab

**2. [Rule 1 - Bug] An existing test assumed every engine note has the prefix**
- **Found during:** Task 1
- **Issue:** `test_import_time_note_is_captured_not_printed` required the prefix on every note. The new sentence has no prefix by design.
- **Fix:** The test accepts `BUILTIN_EXCLUDE_NOTE` or the prefix, and also asserts no `.py` or `rs_corpus` text in the notes.
- **Files modified:** tests/test_run_engines.py
- **Commit:** 2cbe4ab

**3. [Rule 1 - Bug] The new label test depended on test order**
- **Found during:** full suite run
- **Issue:** The import-time note exists only at the first import of the reference module in a process. After an earlier test imported it, `engine_notes` was empty and the test failed in the full run only.
- **Fix:** A `fresh_reference` fixture removes the module from `sys.modules` and resets the three cache variables with monkeypatch. Monkeypatch restores them on teardown.
- **Files modified:** tests/test_run_labels.py
- **Commit:** 27230bc

**4. [Rule 1 - Bug] The fix text of the refusal would say "earlier run" for a hub folder**
- **Found during:** Task 2
- **Issue:** The plan says keep the fix text. For `kind="Eureka hub"` that text would read "the folder of an earlier run", which misleads the user.
- **Fix:** One helper builds the error. The fix text ends with the kind word without its "Eureka " prefix. For the default kind the text is identical to the old text (test checks message and fix).
- **Files modified:** src/mindrian_eureka/run/output.py
- **Commit:** 7909da7
