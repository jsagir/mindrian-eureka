**Command body and exit codes** (command.py 261-294). Copy this try/except shape exactly:
```python
console = Console(quiet=args.quiet, no_color=args.no_color)
try:
    ...
    console.out(canonical_json(summary.to_json_dict()).decode("utf-8").rstrip("\n")) if args.json else console.out(summary.lines())
    return 0

    console.error(error.message, error.fix)
    return error.exit_code
except KeyboardInterrupt:
    console.error("Interrupted. No output was written.")
    return EXIT_INTERRUPTED

    if args.debug:
        raise
    console.error(f"unexpected error ({type(error).__name__}): {error}")
    return 1
```
Exit codes (contracts.py 16-19, 25-50): 0 ok, 1 `RunError`/failure, 2 `UsageError`, 130 interrupted. Raise `UsageError("...", fix="...")` for a wrong flag, a missing env var, or a run folder that is not an Eureka run. Raise `RunError` for a damaged run folder or hash mismatch.

**Console rules** (console.py 1-6, 88-113): progress via `console.stage(name)` / `console.info` to stderr; `console.warn` never silent; `console.error(msg, fix)` prints `eureka: msg` then `  Fix: ...`; the only stdout output is `console.out(...)` (summary lines or `--json`). The console never prompts and never reads stdin. Control characters from file data are stripped by `_clean`. The hub must print the output folder path and file hashes via `console.out`, never the passphrase.

### `hub/writer.py` (service, file-I/O batch) - canonical writer, hashing, staging

**Analog:** `run/output.py` (`canonical_json`, `StagedRun`, `FileDigest`) - reuse by import, do not copy.

**Canonical bytes** (output.py 67-85): sorted keys, indent 2, LF, one final LF, floats rounded to 6, NaN rejected:
```python
cleaned = round_floats(value, digits)
text = json.dumps(cleaned, ensure_ascii=False, indent=2, sort_keys=True, allow_nan=False)
return (text + "\n").encode("utf-8")
```
`hub-data.js` is JavaScript, not JSON file, so wrap: `b"window.HUB = " + canonical_json(data).rstrip(b"\n") + b";\n"`. Pairs and records stay in stable order with ID tie-break (D-07). No clock, no random value, no absolute path (same rule as the manifest, manifest.py 3-6).

**Staging then rename** (output.py 313-413). `StagedRun(out_dir)` creates `.{name}.staging-{pid}` beside the target, `write(rel, data) -> FileDigest` rejects absolute and `..` paths and sets modes 0o700/0o600, `publish()` does `os.replace`, and `__exit__` discards the staging folder:
```python
with StagedRun(out_dir) as staged:
    digests = [staged.write("hub-data.js", data_bytes), staged.write("hub.html", html_bytes), ...]
    staged.write("hub-manifest.json", canonical_json({... [d.as_dict() for d in digests] ...}))
    staged.publish()
```
Caution (PROVEN from output.py 394-398 and `ensure_out_dir_allowed` 251-294): `publish()` replaces an existing folder only if it is an Eureka run folder (has a valid `manifest.json`) or is empty; anything else raises `UsageError`. A rebuilt hub folder has no `manifest.json` of that schema, so a second build into the same `--out` would be refused. The planner must either (a) subclass or parametrize the "may replace" check with a hub marker file (for example `hub-manifest.json` with its own schema id), or (b) write hub files to a fresh folder only. Also `ensure_out_dir_allowed(input_dir, out_dir)` guards input vs output; for the hub the equivalent guard is: `--out` must not equal, contain or sit inside the run folder (CONTEXT: never write into the source or run folder). Default sibling `hub/` next to the run folder; a nested `<run>/hub` is not allowed by D-integration.

**Hub file hashes "next to the run manifest"** (CONTEXT D-07): mirror `FileDigest.as_dict()` (`{path, sha256, bytes}`) into a hub manifest, with a schema constant added beside `MANIFEST_SCHEMA` style ids (`contracts.py` 66-70, for example `"eureka.hub-manifest.v1"`). Include the source run `manifest.json` sha256 so the hub is tied to one run. Do not write into the run folder.

**Cleaning of text for pages**: there is no HTML writer in the repo. Insert data via `textContent` only (UI-SPEC section 9 end); embed data in `hub-data.js`, never in HTML. Escape `</script` and U+2028/2029 inside the JS literal.

## Risks For The Planner

- `StagedRun.publish` and `ensure_out_dir_allowed` only treat an Eureka run folder or an empty folder as replaceable (output.py 251-294, 376-408). A repeat hub build into a non-empty hub folder needs a hub marker and a generalized check, or the second build fails with exit 2.
- `run-info.json` is the only run file allowed to differ between runs; the hub must not read it (CONTEXT code context).
- Phase 2 warning W1 (internal file name in outputs) can reach `reading` and `engine_notes`. Add a scan test on the strings the page shows.
- `pyproject.toml` package-data does not list hub assets yet. An installed wheel would ship no fonts, no lockup and no vendored library.
- Gated build and D-07 byte-identical rule conflict unless salt and nonce are derived deterministically. Decide and document.
