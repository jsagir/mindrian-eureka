<objective>
Build the 3D stage of the Connection graph view: the loader, the map, the bridge shell and chips, the tooltip, the selection effects, the one camera player, the CSP check with the library, and the tests with a 3,000-record scale run.

Purpose: HUB-01 (the map works offline from a file with the vendored library) and HUB-02 (the graph guide, colour meaning and motion rules of the book are implemented as ruled, with the one deviation on record).

Locked decisions this plan implements:
- D-05: the map shows only when at least 15 records are in visible pairs (plan 15 decides the mode; this plan draws the map).
- D-09: record = sphere, pair = line; kinds are named in words in the tip.
- D-10: cobalt lines; yellow only as a sphere and an ink-on-yellow chip; candidate pairs show the printed word "Proposed" in the tip; the dimmed colour is de-emphasis only.
- D-11: spheres carry the neighborhood tint; the tip names the neighborhood.
- D-12: the library is the vendored copy loaded by a relative path; if WebGL or the library fails, the page shows the list of pairs (the shared fallback of plan 15).
- D-13: spheres and curves are fine in the graph; hard edges stay on panels and gates.
- D-14 (OWNER-WORD default): bridge sphere, shell and chip. If the owner dropped bridges in plan 01, remove the yellow sphere, the shell, the chip and the string Gr15, and say so in the SUMMARY.
- D-21: no ambient motion; no particles on any line (a deviation from the book graph guide, recorded by plan 15 and kept here); motion only on a person's action through one player; the token time 760 ms and the token easing; none under reduced motion.
- D-22: 13 px floor, the stage has an aria-label that points to Find and the lists, the stage is not a tab stop.

UI-SPEC section 6.2, section 7.1, section 11.3 and section 13 are the contract. Deck IDs: Gr11, Gr13, Gr14, Gr15 (and Gr12 through the shared fallback).

Starting point. Plan 15 wrote hub-graph.js and hub-graph.css with the view, the diagram, Find, the tour, the pair list and the hook contract. This plan fills the hook contract: the body of `startStage(stageEl)` (plan 15 left a call to `showFallback()` there), the object `G.stage` with `select(sel)`, `clear()`, `flyTo(id)`, `zoom(factor)` and `reset()`, the value `G.instance`, and the call of `showStageButtons()`. It sets the class `hub-graph-stage--3d` on the stage region (the CSS for that class is in plan 15) and sets `G.mode` to `3d`. Read the file and the comment "Hook contract for plan 18" before writing.

Library facts the code relies on (read them from the vendored file and its README before coding): the global `ForceGraph3D`; the three.js scene is reachable with `graph.scene()`; `THREE` is not a global, so code must not construct three.js objects with `new THREE.X`; it may call instance methods such as `clone()`, `material.clone()`, `material.color.set()` and `scale.setScalar()` on objects the library created. The tooltip option `nodeLabel` inserts HTML, so it must be disabled and replaced by an own tooltip element filled with `textContent`. The library may inject one `style` element; Task 3 tests it against the page policy.
