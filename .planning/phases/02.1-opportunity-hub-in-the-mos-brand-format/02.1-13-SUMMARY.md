# Phase 2.1 Plan 13: Reading panel

**Every record and pair opens a labelled, source-linked panel, with a visible synthetic Potential eureka demonstration.**

## Accomplishments

The panel follows the specified field order using source fields, payload facts and copy-deck templates. It shows source file and reference, source links, text, neighborhoods, data flags, partner pairs, score meanings and the required status. Nested proposed-pair blocks also keep their status and both source links. File-linked records offer the catalogue link as well.

Text is split by code point at the payload's 600-character limit and continued in a disclosure. No generated interpretation or hover-opening path is added. Potential eureka records show the yellow chip with ink text and border, the Why heading, their sourced neighborhood names, and the fixed place-to-look explanation.

Close, Escape and the stage background clear selection. Focus moves to the title and returns to the opener when usable, otherwise the h1. The panel is not modal. Desktop reserves its 400 px column; smaller widths use a scrolling sheet no taller than 62 percent of the viewport. Sheet height controls scroll padding and clears on close. Empty desktop state keeps the Rest face.
