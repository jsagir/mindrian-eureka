**A Playwright driver and Python wrapper that load a file URL in Chromium and Firefox, emulate motion, colors, no-JS and no-WebGL, and prove that a page makes no network call; plus a probe record that settles WebCrypto, CSP, WebGL, the npm pin, the crypto dependency and the engine cut-off keys with a fallback for each.**

## Findings that change later plans

- **Firefox misses some remote requests in the route.** Firefox upgrades a remote `http:` image to `https:` and the second request does not reach the Playwright route (it reached DNS in a first test). The driver now records every remote `request` event too, and adds a second layer: Firefox sends remote traffic to a closed local port, Chromium resolves no host name. A route-only harness would have missed a leak.
- **Firefox reports no request events for file URLs.** `localRequests` is complete in Chromium only.
- **Firefox 146.0.1 does not apply a meta CSP to local file subresources.** With `default-src 'none'` an external local script still ran. It did enforce the policy on inline script, `data:` images, remote loads and fetch. So the CSP is a real control against leaks and inline code, and not against local file loads in Firefox. The rule "no remote URL, no inline script" must also be enforced by the static scan (plan 09).
- **The built page cannot use inline `style=` attributes or inline scripts** under the chosen CSP. Setting `element.style.x` from script works.
- **WebKit does not start here** (missing system libraries: libgtk-4, libgraphene, libxslt, several GStreamer libraries). Safari is not covered. Plan 19 needs a human check.
- **Both engines drop pairs below `min_percentile` before ranking** (`opportunity_pairs/algorithm.py` line 318, `hsi_reference.py` line 1095; read from code, not run). The run folder may therefore not hold pairs below the cut-off. The "Show weaker pairs" control (UI-SPEC section 7.5) may have nothing to show on a default run. Plan 08 must check this. The wording engine default `min_percentile` is 0.0, which hides nothing.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The route alone did not detect all remote requests in Firefox**
- **Found during:** Task 1 (the Firefox negative-control test failed on the image)
- **Issue:** Firefox upgrades the http image request to https and that request skips the route. The page then tried a real DNS lookup.
- **Fix:** The driver records remote `request` events as well (one entry per URL and type) and adds the second layer described above. Verified with a debug run: the unrouted image now fails with a proxy refusal.
- **Files modified:** tests/hub_browser/driver.cjs
- **Commit:** 329eb70

**2. [Rule 2 - Missing critical] The CSP decision rule could not tell a working policy from an ignored one**
- **Found during:** Task 2 (a `default-src 'none'` page still ran its local script in Firefox)
- **Issue:** The plan rule only asks that all four types load and the fetch is reported. A policy that is not applied could pass it.
- **Fix:** Each candidate page also carries an inline script, an inline style attribute, a `data:` image and a remote image. A candidate counts as enforced only when the inline script and the `data:` image are blocked and the remote image and the fetch are reported. A test checks that a block-all policy is detected, and the control (no policy) must fail the enforced check.
- **Files modified:** tests/test_hub_browser_probe.py
- **Commit:** c6fa695

**3. [Rule 3 - Blocking] Font request check cannot use request events in Firefox**
- **Found during:** Task 2
- **Issue:** Firefox reports no file requests, and the probe font is not a real font.
- **Fix:** "Font requested" means no font-src violation and a face state of `loaded` or `error`. The record states this.
- **Files modified:** tests/test_hub_browser_probe.py, docs/brand/hub-probe-results.md
- **Commit:** c6fa695

**4. [Rule 2 - Missing critical] Driver error text was cut to one line**
- **Found during:** Task 2 (the WebKit error read only "browserType.launch:")
- **Fix:** The driver keeps the first three non-empty lines of a launch error.
- **Files modified:** tests/hub_browser/driver.cjs
- **Commit:** c6fa695
