# Phase 2.1 Plan 09: Local writer and command

**One offline command publishes a deterministic hub folder after validating provenance and canonical assets.**

## Accomplishments

The writer uses the existing folder guard and StagedRun, verifies the payload before publication, checks static asset hashes, records every output digest in hub-manifest.json, and preserves run and source folders. Relative source links encode every path segment; missing or escaping files use catalogue links with one count warning.

The lightweight hub command uses existing console, help, exit-code, error, and stream conventions. The CLI diff adds only the import, registration, and dispatch. Contributor checks include hub modules and document the required-browser environment flag.

Static scanners cover remote HTML and SVG attributes, speculative loads, meta refresh, CSS load rules, authored JS network APIs and URLs, and unknown text extensions. Negative controls prove forbidden constructs fail. Vendor code and fonts keep their separate byte/hash checks. Source content remains exempt from authored-copy scans.
