<objective>
Run the book review on the built page, capture and inspect it at five widths, measure what can be measured, return the gaps to the book, and record the result without claiming more than was seen.

Purpose: HUB-02 (the review passes and the decisions are cited), and the check of HUB-01, HUB-03 and HUB-04 on the finished page.

Locked decisions this plan implements:
- D-02: `mos-brand review --file {hub page}` must pass before the phase closes; the decisions file gets its results section; a person approves before anything publishes (plan 17 records it).
- D-03: every book-silent item and every new gap goes back to the book as a proposed segment. The return is made through the CLI run workflow in this repo (stage return-learning); nothing is written into ~/mos-brand.
- D-23: every screenshot and snapshot comes from the public fixture. No private room data and no personal names enter the repo.
- D-14, D-17 follow the owner's answers in docs/brand/hub-design-decisions.md.

Rules for this plan (UI-SPEC section 15 and the evidence rule of the agent protocol): do not claim a visual result without a screenshot you opened and looked at. Open every saved image with the Read tool and write what you see. Do not claim a save without a confirmed file. Say "Implementation complete; visual verification pending" when that is the state.

"Pass" for `mos-brand review`: the command ends with exit code 2 and status REVIEW-REQUIRED, and the `findings` list is empty. Exit code 1 and status BLOCKED mean a blocker (for example an em dash in prose). The planner proved both outcomes on 2026-10-24 with a sample page.
