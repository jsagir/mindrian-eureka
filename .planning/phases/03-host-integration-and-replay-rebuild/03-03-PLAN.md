<objective>
Build the Eureka side of the approval step: the plan digest, the single-use receipt store, the start check, and the plan builder that tells the host exactly what a run will read, write and rank before anything starts (D-05, D-11, HOST-01).

Purpose: success criterion 2 of the phase says the run must not start without the approval step. Eureka cannot prove that a person approved. It can make the order plan, then approval, then start mechanical, bind the start to the exact bundle that was planned, and keep an audit row. This plan builds that mechanism without the MCP layer, so the tools of plan 03-05 stay thin.
Output: 2 new modules, 2 new test files, 3 task commits by explicit path, 1 summary commit. No push.
</objective>
