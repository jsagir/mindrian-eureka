## Decisions Made

- Byte-copy fallback for the token sheet; the lock reconciliation stays with the owner (D-03a, plan step 2).
- `verify.py` evaluates the TypedDict hints with `get_type_hints(include_extras=True)`; `__optional_keys__` cannot be used because `contracts.py` keeps string annotations (`from __future__ import annotations`) and Python 3.12 does not detect `NotRequired` inside a string. Missing required keys and extra keys are still refused (probe: `{'zz': 1}` against `PayloadPair` reports both).
- B15 and P10 registered in UI-SPEC section 9 (2 additive rows) rather than reusing an existing id, because `tests/test_hub_copy.py` makes the spec the contract for the deck and the plan's tests pin the ids.
- The scale run is built once per module (`tmp_path_factory`) so the 3 tests share 1 build; `build_scale_run` returns the summary and the seconds too.
- 5 commits, 1 per task, as the orchestrator asked.
