# Phase 02.2 Plan 04: Carry-in bundle builder and launchers Summary

**`scripts/build-partner-bundle --target <name>` writes one folder `eureka-partner-bundle-<target>` with the uv binary, the source from `git archive HEAD`, the hashed requirement list, the copied model, the mapping, a side-car slot, the guide, `start.sh` and `start.ps1`, and a manifest with the sha256 and byte size of every file; the launcher syncs offline, runs doctor, run and hub with the real `--out` flag, stops on a doctor failure and prints the sequence under `--dry-run`.**

## Accomplishments

- `builder.py`: `TARGETS` with the 3 D-07 names and their uv triples, archive kinds, `--python-platform` values, pip platforms and managed Python keys; `resolve_target("host")` maps this machine to `linux-aarch64` (`aarch64-unknown-linux-gnu`, `aarch64-manylinux_2_28`); an unknown name raises `BundleError` that lists the 4 accepted names.
- `build_bundle` runs 10 small steps in order: preconditions (uv on PATH, `--online` for any target other than host, for `--wheels download` and for `--allow-model-download`, docker on PATH for `--docker`, all before any file is written), the bundle folder (refused when non-empty), `source/` from `git archive --format=tar HEAD` through `tarfile` with the data filter, `requirements.txt` from `uv export --frozen --no-dev --no-emit-project --extra modern-encoder --extra hub-gate --offline` (1194 lines with `--hash=sha256:`), `uv` copied byte for byte (mode 755) for the host, `wheels/` only online, `model/` copied with `symlinks=False` from `--model-path` or `discover_model(None)` (recorded as `explicit`, `environment`, `hf-cache` or `absent`; never downloaded without `--allow-model-download`), `python/` only with `--python-from`, the mapping, the side-car README and example, the guide, the launchers, the docker variant, then `BUNDLE-MANIFEST.json` last.
- The manifest holds `schema`, `label` (imported `LABEL`), `target`, `engine_version` 0.1.0, `source_commit`, `built_at` (UTC, seconds, `Z`), `builder` (host, uv_version, python_version, online, wheels, model, python, docker, docker_image when used) and `files` sorted by path with `bytes` and `sha256`; it holds no absolute path.
- `main(argv)`: `--target {linux-x86_64,windows-x86_64,macos-arm64,host}`, `--out` (default `dist`), `--online`, `--wheels {download,skip}`, `--model-path`, `--allow-model-download`, `--python-from`, `--docker`; errors print `error:` and `fix:` to stderr and return 2; success prints the bundle path, the file count and the manifest sha256.
- `launchers.py`: `start.sh` (bash, `set -euo pipefail`, every path quoted, no `eval`) and `start.ps1` run the same sequence: `uv sync --offline --no-index --find-links <bundle>/wheels --extra modern-encoder --extra hub-gate` (or a plain `uv sync --offline` with a printed note when `wheels/` is absent), `uv run --offline eureka doctor` (non-zero exit prints `Doctor found a problem. Read the fix above, then run start.sh again.` and exits 1), `eureka run <input> --out <output> --mapping <bundle>/mapping/technology-audit-export.json [--text-sidecar <first csv or json under sidecar/ other than the README and the example>]`, `eureka hub <output> --out <output>-hub`, then `xdg-open`, `open` or the printed path (`Start-Process` on Windows). Input defaults to `../input` next to the bundle (else `./input`), output to `../output`. `--dry-run` / `-DryRun` prints 5 `would run:` lines and exits 0 before anything runs.
- Launcher environment: `PATH` prefixed with the bundle, `UV_OFFLINE=1`, `UV_NO_PROGRESS=1`, `UV_PYTHON=3.12`, `UV_CACHE_DIR=<bundle>/.uv-cache`, `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `UV_PYTHON_INSTALL_DIR=<bundle>/python` and `MINDRIAN_EUREKA_RS_MODEL_PATH=<bundle>/model` when those folders exist.
- Docker pair: `docker load -i eureka-image.tar`, then doctor, run and hub with `docker run --rm --network none --read-only --cap-drop ALL --security-opt no-new-privileges --tmpfs /tmp` and the input (ro), output, model (ro), mapping (ro) and sidecar (ro) folders mounted; the image name comes from `builder.docker_image` in the manifest with the default `mindrian-eureka:local`.
- `sidecar/README.md`: 9 lines on the CSV and JSON formats, the thin-record rule, the drop location and that the file never leaves the machine; no label literal, no person, no partner.
- Guide: section `## How the bundle is built` before `## Privacy` (10 to 11 headings, nothing else changed); README: 1 pointer sentence.
