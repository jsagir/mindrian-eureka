# Phase 02.3.1 Plan 01: The run reading band Summary

The black band reads the whole run in plain words from sourced numbers only (`describe_run`, a pure function of the payload), renders on the server and in the script from the same 14 deck strings, stays empty and hidden on the locked page, and the router no longer raises E05 for the in-page anchors.

## What was built

- `src/mindrian_eureka/hub/pattern.py`: `describe_run(payload)` returns `{"state", "lines"}`. States in rule order: `none` (no pair ranked), `hidden` (pairs ranked, no record in a shown pair), `grouped` (2 or more neighborhoods or at least 1 bridge), `single` (otherwise). Lines are deck keys with slot values; the last line is always G16. Values are ints from the payload or the two engine short names. The module uses no numeric literal other than 0, 1 and 2 (a test parses the source with `ast`).
- `contracts.py`: `PATTERN_STATES`, `PatternLine`, `PayloadPattern`, `Payload.pattern` (`NotRequired`). `model.py`: `payload["pattern"] = describe_run(payload)` at the end of `build_payload`. `verify.py`: shape, state, deck key, int or string value, dash and internal-name checks for the pattern.
- `deck.py`: 14 G17 strings under "9.8 run reading band". UI-SPEC 9.8 holds the same table; the ID count in `test_hub_copy.py` grew from 88 to 89 (same change as B15, B16 and P10 in Phases 2.2 and 2.3).
- `page.py`: `_band(payload)` renders `<section id="hub-band" class="hub-band mos-ground-ink" aria-labelledby="hub-band-label">` with the label (yellow square marker plus G17.label), one reading paragraph (all lines except G16, joined by one space), the G16 limit paragraph (`mos-secondary`), and the link to `#hub-data-check`. The band sits after `hub-counts` and before `hub-nav`. The locked page holds `<section id="hub-band" hidden>` with no content.
- `hub-core.js`: `band(payload.pattern)` builds the same four children with `app.el` and `app.fmt` after start; without a pattern the band stays empty and hidden. `route()` returns early for `hub-results`, `hub-data-check`, `hub-footer` and `hub-band`. `deepLink` is unchanged.
- `hub-band.css`: tokens only (ink, paper, paper-dim, yellow); 1 column under 768 px, `150px minmax(0, 1fr) auto` from 768 px; the reading panel reserve at 1024 px; no animation, no transform.
- `docs/brand/hub-model-rules.md`: section "Run reading band" with the state rules, the source table, the no-threshold statement, the label wording choice, the honesty limits and the line "Book silent on a generated reading of a run: proposed segment."

Public fixture, PROVEN by a build: state `single`; keys G17.read, G17.both, G17.spread, G17.single, G17.top_k, G16; values 36 records, 63 and 200 pairs, 38 pairs in both lists, 36 records in a shown pair, 0 in none, wording engine limit 200.
