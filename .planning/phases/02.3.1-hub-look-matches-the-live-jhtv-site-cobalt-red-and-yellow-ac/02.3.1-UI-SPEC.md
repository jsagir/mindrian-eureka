# Phase 2.3.1 UI-SPEC: the hub in the look of the target site

## How to read this file

The book is the reference; the owner's session decisions rule where they differ (R-01). The target is the live site the owner named on 2026-11-08. No name, no screenshot and no page text of the target is stored in this repository; only its stylesheet (`evidence/target-site.css`). Each rule below is one line. The look contract (`tests/hub_look_contract.py`) is the testable form of sections 1 to 3; its deviations are in `docs/brand/hub-design-decisions.md`, section "Phase 2.3.1 look change".

## 4 Band

The run reading band is specified in `docs/brand/hub-model-rules.md`, section Run reading band (plan 01). State rules in one table:

| State | Condition | Lines |
|-------|-----------|-------|
| none | no pair ranked | G17.none, G16 |
| hidden | pairs ranked, no record in a shown pair | G17.hidden, G16 |
| grouped | 2 or more neighborhoods or at least 1 bridge | G17.read, G17.both, G17.spread, G17.hoods, G17.bridges, G17.top_k, G16 |
| single | otherwise | G17.read, G17.both, G17.spread, G17.single, G17.top_k, G16 |

Look: ink ground, paper text, yellow square marker 10 px before the uppercase mono label "What this run shows" (O-04), one paragraph of the reading, the paper-dim limit sentence (G16), one underlined link to the data check.

## 6 Figures

Specified in `docs/brand/hub-figure-rules.md` (plan 04). `hub.css` holds one rule for each class of the figure class vocabulary, tokens only, so the theme changes a figure. The page inserts a figure only through `HubApp.figure`, which allows 7 tags and 21 attributes and returns null on any doubt.
