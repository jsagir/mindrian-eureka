## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] A return by the Back knob did not restore the place**
- **Found during:** Task 2, `test_return_keeps_place` (scroll 0 against 5377 in both browsers).
- **Root cause:** `history.back()` lands on the bank entry's own hash, which is `""` (the hub loads with no hash) or `#bank`, not `#/`. That hash takes the Phase 2.1 branch of `route()`, which never called `restorePlace`. A second cause sat behind it: the browser's own scroll restoration of the history entry can overwrite the hub's placement.
- **Fix:** `fromPage` is read at the top of `route()` and `restorePlace` runs in the Phase 2.1 view branch too; `history.scrollRestoration = "manual"` at start. Measured after: the return scrolls to 5377 and focuses the link that was used, in Chromium and Firefox.
