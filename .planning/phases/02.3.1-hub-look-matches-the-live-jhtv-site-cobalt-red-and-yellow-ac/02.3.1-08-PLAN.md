## Trust boundaries

| Boundary | Description |
|----------|-------------|
| URL fragment to router | A typed or pasted hash selects a page |
| payload record and pair text to page DOM | Source text, titles and terms render in many places |
| payload figure string to page DOM | An SVG string is inserted next to text |
| history and key events to navigation | Back, arrows and Escape change the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.3.1-45 | Tampering | Hash grammar | mitigate | A fixed grammar: engine key must be an own property of the payload engines, the rank must match `^[1-9][0-9]{0,8}$` and exist, the id is decoded in a try block and looked up in a Map. Every other text under `/` gives E05 and changes nothing. Tests use `__proto__`, `constructor`, leading zeros, bad percent codes and empty ids. |
| T-02.3.1-46 | Elevation of privilege | Figure insertion on pages | mitigate | Only `HubApp.figure` inserts a figure and it returns null on any unsafe string. The twin and the description text are built from text nodes and `textContent`. |
| T-02.3.1-47 | Tampering | Hostile titles, ids and text on pages | mitigate | Text nodes only through `HubApp.el`. The hostile-run tests open pages for ids `bank`, `hub-results` and `__proto__` and for markup in titles and assert that nothing runs and no extra element exists. |
| T-02.3.1-48 | Repudiation | A page that shows a claim the data does not support | mitigate | Pages read the payload only: numerals are the payload strings, words are the payload terms, the reading is the payload sentence. Every pair page and record page carries the label chip "candidate, not verified" (asserted by a test, because the title band that holds the status line is hidden on a page route). |
| T-02.3.1-49 | Denial of service | Large record text on a page | accept | One page is in the DOM at a time (`replaceChildren`); paragraphs are chunked; the payload already holds the full text and the panel already renders it. |
| T-02.3.1-50 | Information disclosure | Locked build | mitigate | `hub-pages.js` touches no DOM at load and the site section is created only after `start()`. The locked page holds no run data (the old privacy test stays). No storage is used by this plan. |
| T-02.3.1-51 | Tampering | History confusion: the Back knob lands on a neighbouring page after a jump over several entries | accept | The rule uses the previous displayed page; a jump over several history entries can mislead it. | T-02.3.1-52 | Denial of service | Key handlers steal keys from a form field or a screen reader | mitigate | The handlers ignore events with a modifier key, a prevented default, or a target that is an input, textarea, select or editable element, and act only on page routes (Escape also closes the panel as before). |
