# Phase 02.3.1 Plan 03: The target shell look Summary

The generated hub page now has the target's shell: a sticky paper header with the lockup, a cobalt mono label, the three view links and a bordered Data check link; one 1200 px wrapper; a cobalt eyebrow with a square red dot over a Figtree display heading and an ink rule; a four-column counts strip between ink rules; cobalt links; ink buttons that turn cobalt on hover; 1 px hairlines; and a safe way to insert generated SVG figures. Every role is pinned against the stored target stylesheet by a static look contract, and the owner ruling with its 34 deviations is written in the decisions record.
