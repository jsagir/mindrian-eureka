## The class vocabulary (shared with plan 03, which writes the CSS)

The figures set `class` on every shape and text. The page stylesheet (`hub.css`, plan 03) maps each class to a book token, so the theme changes the colours. Each shape also carries `fill` or `stroke` attributes in the light palette (paper `#F7F5EE`, white `#FFFFFF`, ink `#111111`, soft `#4B4943`, quiet `#ECEAE2`, cobalt `#1F3FBF`, red `#D6281F`, yellow `#F2C200`) as a fallback outside the page.

| Class | Meaning | Rule (token) |
|-------|---------|--------------|
| f-paper | ground | fill paper |
| f-frame | frame | no fill, stroke ink, width 6 |
| f-rule | vertical or horizontal rule | stroke ink, width 6 |
| f-panel | record marker or record panel | fill white token, stroke ink, width 5 |
| f-ink | ink block, ink strip, shared-word square | fill ink |
| f-blue | meaning bar, cobalt agreement block | fill blue |
| f-red | wording bar | fill red |
| f-yellow | Potential eureka block | fill yellow, stroke ink, width 6 |
| f-tick | scale tick | stroke ink, width 2, opacity .35 |
| f-fan | decoration line | stroke ink, width 2, opacity .55 |
| f-link | dashed proposed link | stroke ink, width 8, dash 28 on and 32 off |
| f-track | bar track | fill quiet, stroke ink, width 3 |
| f-band | shared-word band | fill ink |
| f-chip | word chip | fill paper, stroke ink, width 3 |
| f-chip-on | word chip on the band | fill paper, stroke paper, width 3 |
| f-mono | label and chip text | font code, 28 px, weight 500, fill ink |

Text in the chips of the band uses `f-mono f-chip-t`. The word Proposed is printed in the HTML beside every picture (the row role word, the page eyebrow).

## Encoding rule

Canvas for both variants: viewBox 0 0 1400 934 (the target picture's size, PROVEN). Ground, frame inset by 3 (x 3, y 3, width 1394, height 928, stroke 6).

Scale of a score bar (decision): the wording engine declares a 0 to 1 scale (its `score_meaning` text). The unusual-pairs engine puts both scores on a common scale that is not 0 to 1. For an engine `lo` and `hi` are: for the wording engine 0 and 1; for the unusual-pairs engine the smallest and the largest of 0, 1 and every wording or meaning score of its shown pairs. A bar length is `(score - lo) / (hi - lo)` of the track, clamped to 0 to 1, in whole pixels (round half up). The description names the scale in numbers. (The owner brief said "0 to 1"; for the unusual-pairs engine that would clip real scores; the fixture's unusual-pairs meaning scores reach 1.299088, PROVEN.)

Agreement (`agree`): the pair id has an entry in both engines' lists and a wording-engine entry has `confirmed` true. Potential eureka (`eureka`): `bridge` is true for either record.

Card variant (no text):
- Rule: ink line at x R from y 0 to y 934, with R = 1100 + 20 * (first byte of sha256(pair_id) modulo 3). The same byte-based seed places 7 fan lines: line i runs from (850, 467) to (R - 20, 330 + 60 * (byte i + 2 modulo 5) + 24 * i). They are decoration (class f-fan, drawn before the data shapes).
- Markers: record A at x 70, y 110, 150 by 150; record B at x 400, y 110, 150 by 150 (class f-panel), each with an ink corner square of 50 (class f-ink); a dashed link from x 226 to x 394 at y 185 (class f-link). They stand for the two records and the proposed pair; they carry no data.
- Bars: ticks at x 70, 450 and 830 from y 300 to y 650 (class f-tick). Meaning bar: x 70, y 330, height 126, width `round(760 * t)`, minimum 8 (class f-blue). Wording bar: x 70, y 500, height 126 (class f-red).
- Shared words: one ink square 64 by 64 at x = 70 + 96 * i, y 720, for i below the number of shared words (at most 8 squares drawn; plan 02 lists at most 6).
- Right column x from R + 3 to 1397: cobalt block at y 150, height 140 when `agree`; yellow block at y 3, height 140 when `eureka`.
- Description (plain words, real numbers): "Meaning score {x} and wording score {y}, on a scale from {lo} to {hi}. {n} shared distinctive words: {list}. [Both engines list the pair and the second signal confirmed it. The cobalt block marks that.] [A record of the pair is a Potential eureka. The yellow block marks that.] The thin lines are decoration. This is a screening picture, not evidence. candidate, not verified." Title: "Pair {rank} of the {engine}: meaning, wording and shared words".

Detail variant (with text; all sizes in canvas units; the executor tunes the coordinates and records them, inside these rules):

Title: "The core of pair {rank} of the {engine}: two records, their words and what they share".

Text rules: every title and word is XML-escaped; dash characters (code points 8211 and 8212) in a title become a hyphen; no other change of a title. A record with an empty title shows the text "(no title)" in the figure (the fixed string `G18.no_title`).
