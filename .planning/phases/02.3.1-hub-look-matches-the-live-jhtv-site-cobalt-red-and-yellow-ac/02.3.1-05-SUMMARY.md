# Phase 02.3.1 Plan 05: Light and dark theme with a header toggle Summary

**The hub has a light and a dark theme on the book tokens: a header toggle with aria-pressed and a visible word, the choice kept under one localStorage key inside try and catch, the system preference as the default, no flash (the early head script applies the saved choice), the book's own reverse lockup in dark, a ring around the Theo tile, figures that follow through the class rules, and a measured contrast table for every pair in both themes.**

## What was built

- `hub-theme.css` (last in `STYLE_ORDER`): `:root { color-scheme: light; --hub-ring: transparent; --hub-dim: #d8d4c8 }`; `:root[data-theme="light"]`; `:root[data-theme="dark"]` with the 13 custom properties of the plan's table and `color-scheme: dark`; the same list under `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) }`; the lockup swap (paper hidden, reverse shown) in both dark scopes; `.hub-role--bridge, .hub-graph-chip { color: var(--mos-paper) }` and `.mos-ground-ink :focus-visible { outline-color: var(--mos-paper) }` in both dark scopes; `#hub-face, #hub-panel img { box-shadow: 0 0 0 3px var(--hub-ring) }`; the toggle (inline-flex, 44 px, 10 px 13 px padding, 1 px ink border, transparent fill, 13 px 600, ink fill and paper text on hover, colour transitions only); the half-filled square mark from 768 px; `.no-js .hub-theme-toggle { display: none }`; reduced motion sets the toggle transition to none. No filter, no blend mode, no hex outside the two token blocks.
- `hub-boot.js`: after the class switch, one IIFE with `try { localStorage.getItem("hub-theme") }`; only the exact strings `dark` and `light` reach `data-theme`; the catch does nothing (storage can be blocked).
- `hub-theme.js` (after `hub-core.js` in `SCRIPT_ORDER`): strict IIFE; `current()` reads `data-theme`, else `matchMedia("(prefers-color-scheme: dark)")`; `render()` sets `aria-pressed` and the `.hub-theme-label` text from the deck (`HubApp.fmt` when `HubApp.copy` exists, else `window.HUB_COPY`); click sets `data-theme`, saves inside try, renders, emits `HubApp.emit("theme", next)`; a media `change` listener re-renders and emits when no choice is saved. Deck keys comment for the coverage test.
- `page.py`: `LOCKUP_REVERSE_FILE`; two lockup images (`img.hub-lockup.hub-lockup--paper`, `img.hub-lockup.hub-lockup--reverse`, both with the G03 alt); `button#hub-theme.hub-theme-toggle` (`type="button"`, `aria-pressed="false"`, `aria-label` G03.theme.name) with `span.hub-theme-dot` (aria-hidden) and `span.hub-theme-label` (G03.theme.light) after the action link, on the open and the locked page; `hub-theme.css` last in `STYLE_ORDER`, `hub-theme.js` after `hub-core.js`.
