<objective>
Write the typed engine facade for `eureka run`. It calls the unusual-pairs engine ("Find Unusual Pairs Across a Research Collection") through the library runner, and the wording-and-meaning engine ("Rank Unusual Pairs by Wording and Meaning") through the building blocks of hsi_reference.py in the order of the recorded rebuild. It adds no scoring code.

Purpose: Success criterion 1 (ranked pairs from both engines) and the settings and seed half of criterion 2. The wording-and-meaning adapter run_hsi cannot reproduce the recorded rebuild (token chunks instead of 200-word chunks; limits), so the facade calls the building blocks directly (RESEARCH section 1, Pitfall 1).
Output: engines.py, tests/test_run_engines.py and the `stub_encoders` fixture.

Locked decisions from 02-CONTEXT.md that this plan implements:
- "Unusual-pairs engine path = repo eureka-pair-scout... Plugin script and r-and-d script are not called."
- "Wording-and-meaning engine settings = the recorded rebuild: tier 1, top-k 200, on a scratch copy." The facade never calls hsi_reference.main on the user folder (main writes cache files into the room it reads).
- "Record engine version and the stable tie-break rule (stable descending top-7 term sort) in the manifest." manifest_engine_sections returns both.
- "Offline: doctor and run make no network calls. No model downloads." The encoder is built with local_files_only=True; the offline variables are set before any import of the engines.
- OQ-1: both legs score `title + "\n\n" + text` (Record.model_text).
- ml-pipeline (reproducibility parts): seeds, library settings and the params hash are recorded; no MLflow or similar.
- python-pro rules (typed, dataclasses, no bare except, no mutable defaults, Google docstrings, pytest fixtures) for this new module. Calls into the untyped hsi_reference stay inside this facade.

Public API (plan 02-06 consumes these names exactly):
- `prepare_offline_environment() -> None`: sets HSI_NO_AUTO_INSTALL=1, HF_HUB_OFFLINE=1, TRANSFORMERS_OFFLINE=1 (assignment, not setdefault) and setdefault for HF_HUB_DISABLE_TELEMETRY=1 and TOKENIZERS_PARALLELISM=false.
- `apply_thread_limits(threads: int | None) -> None`: None is a no-op. A value below 1 raises UsageError. Otherwise sets OMP_NUM_THREADS, OPENBLAS_NUM_THREADS and MKL_NUM_THREADS to the value, and calls torch.set_num_threads only when torch is already in sys.modules.
- `load_local_encode(model_dir: Path) -> Callable[[list[str]], NDArray[np.float64]]`.
- `run_unusual_pairs(records: Sequence[Record], *, model_dir: Path, top_k: int, max_artifacts: int, cache_path: Path, objective: str = "", progress: Callable[[str], None] | None = None) -> UnusualPairsOutcome`.
- `run_wording_and_meaning(records: Sequence[Record], *, encode: Callable[[list[str]], NDArray[np.float64]], top_k: int, progress: Callable[[str], None] | None = None) -> WordingOutcome`.
- `wording_params(top_k: int) -> dict[str, Any]` and `wording_params_hash(top_k: int) -> str`; constant `RECORDED_PARAMS_HASH = "7affae3c94c6bed9"`; constant `TIE_BREAK`.
- `manifest_engine_sections(unusual: UnusualPairsOutcome, wording: WordingOutcome) -> dict[str, Any]` with the keys "engines", "settings", "seeds", "engine_notes".
- Dataclasses `UnusualPairsSettings`, `WordingSettings`, `UnusualPairsOutcome` (result: dict, settings, capability_version), `WordingOutcome` (pairs: tuple[dict, ...], settings, params_hash, reference_sha256, engine_notes: tuple[str, ...]).
- Fixture `stub_encoders` in tests/conftest.py: patches `mindrian_eureka.run.engines.load_local_encode` to return `hashing_encode` and patches `runner.SentenceTransformerEncoder` to `HashingEncoder`. Plan 02-06 must call `engines.load_local_encode` through the module attribute so the patch works.

Tooling for every verify command (user-level tools on PATH): `PYTHONPATH=src python3 -m pytest <files> -q -p no:cacheprovider`; `mypy --strict --ignore-missing-imports --follow-imports=silent --python-executable "$(command -v python3)" --cache-dir /tmp/eureka-mypy <new files>`; `ruff check --select E,F,I,UP,B --line-length 100 --no-cache <new files>`. Strict typing applies to new files only. Never write the short engine codes (regex \b(R[S]|H[S]I)\b) in text a user can see; code identifiers keep their names.
