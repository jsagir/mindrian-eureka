<objective>
Make the column-to-room-section map data in the mapping file (D-02, SEED-02) and make the run keep what the seed needs: for each CSV record, the state of every mapped cell, with no cell value.

Why this plan comes first. The seed command (plan 02.3-02) reads only a finished run folder. The run folder holds the carried cells and the assembled text. It does not hold the money cells, the list cells or the people cells, and it does not say which text column was blank. D-02 says `known` = every mapped column that is filled and `feed_next` = every mapped column that is blank. The run must therefore record the fill state of each mapped cell. This plan adds that record. It keeps the Phase 2.2 rule: people, money and company-list values never enter an output.

Scope. Mapping schema and loader; cell states in the corpus builder; one conditional key in `corpus/records.jsonl`; one conditional key in the manifest; the hub reader additions that the seed reader and the hub plan reuse; the shipped mapping block. No seed code. No ranking change. No change to `wording_params`; the recorded hash `bea4c100c2013300` stays.

Output: 7 edited source files, 1 edited data file, 2 new test files, 3 edited test files (additive), 3 task commits by explicit path, 1 summary. No push.
</objective>
