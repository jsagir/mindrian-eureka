# Phase 02.3 Plan 04: Seed command row in the hub Summary

**Under each pair of a seedable run the bank prints `eureka seed RUN_FOLDER --pair <pair id>` as text to copy, with one chip label and one plain-English hint. The page runs nothing: no button, no clipboard code, no handler. A run that cannot be seeded gets the same hub bytes as before.**

## Decisions

1. **Hint position.** The plan said to put the no-script hint in `_engine_lists`. That function also builds the graph list, so the hint would print twice. The hint is in the bank section before the bank list; it appears once.
2. **Rows per page.** The no-script page lists each pair in both the bank list and the graph list, so the row count in the page is twice the pair count (22 for 11 pairs). The test counts rows and seed rows against each other.
