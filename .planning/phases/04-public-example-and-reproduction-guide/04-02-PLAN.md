Ship the small public example of EXM-01: the dataset (reused in place), a reference run of the current engine, the expected-hash file, a README with the status, and tests that include a fresh-checkout run.

Output: `examples/public-example/` (README, expected-hash file, reference run) and two test files.

- P-08: the real-model fresh-checkout test is opt-in with `EUREKA_EXAMPLE_REAL_RUN=1`, like the other real-model test of the suite. The default suite checks the shipped reference run with no model.
