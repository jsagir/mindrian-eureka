<objective>
Make the embedding cache safe against a mix of encoder setups: the key holds the full encoder identity, the schema version moves from 1 to 2 so old entries are ignored, a stored vector is checked against the expected width on every hit, and each profile has its own cache file (D-05, D-07, D-09; ENC-03).

Purpose: the research found that the key lacks dimension, dtype, device and prefix, so a GPU or a new model could silently reuse wrong vectors. This plan closes the gap in the cache itself. It takes the identity as a plain mapping, so it does not import the spec layer of plan 05-01 and the two plans can run in the same wave. The runner passes the identity in plan 05-03.
Output: 2 changed source files, 1 new test file, 2 task commits, 1 summary commit. No push.
