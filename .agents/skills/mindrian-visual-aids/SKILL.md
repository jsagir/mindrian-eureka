# Work in the Mindrian production system

Before creation, invoke the installed mindrian-production skill, read its local references/brand-context.md, and complete tools check/install/prepare for task visual-aid. Resolve missing inputs and tooling first. Use only real capabilities; never invent an installation or review.

Name one relationship, mechanism or change the reader should understand. Show it spatially or causally; a text box is not a visual explanation. Keep editable labels inside bounds, preserve the status of proposed connections, and provide a meaningful still. Choose static, css, react or react-scroll from the requested behavior. Do not remove interaction merely because no packaged component exists.

Apply actual source and asset guidance returned by tools prepare. Record real checks and remaining reviews. Preparation is not approval or authorization to publish.

Use the selected experience/visual-language grammar. For tools prepare, supply visualForm (graph-data, graph-relationships, matrix-2x2, pyramid, system or framework), encoding, motionMeaning and stillState. Read the returned visualRecipe and its exact child GUIDE.md. The Theo Faces language guides the thinking move; a face is not required inside every diagram. Do not interchange a data graph with a network, an argument pyramid with a knowledge ladder, or a return arrow with proven causality.

For supported React structures, use the packaged Shaper exports from `mindrian-design-system/shaper` and its styles subpath. Read the nested Shaper GUIDE before choosing a component. Six initial components are available; do not treat them as coverage of every framework. Preserve the framework variant and source status, supply real project labels, and keep reduced motion and the complete still.

Animated Shaper production must apply the nested motion ruling. Use useShaperMotion, register the component thinking move, declare purpose and relevance, and pass the returned motion envelope and progress. Interactive React preparation requires motionPlan before creation. No independent timers or ambient SVG/CSS loops. New custom structures need an explicit motion contract.

Critical geometry ruling: choose the form from what the explanation means. React, the logo and the Mondrian-inspired identity must not force square boxes, straight connectors or right angles into every visual. Preserve valid circles, arcs, curves, organic contours and irregular framework boundaries. Straight scales and hard edges remain appropriate when meaningful. Do not blindly round everything either. State the reason in the existing encoding brief, and make motion follow the chosen geometry.
