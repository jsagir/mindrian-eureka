# Brand workflow for the hub

This file is the declared workflow file of the opportunity hub. The brand tool links to it.

1. Brief: read the output of `mos-brand context` for the hub job and the UI-SPEC copy deck before any page work.
2. Produce: write the hub files from the packet assets and tokens. Cite the book segment for every design choice.
3. Review: run `mos-brand review` on the built page and on rendered snapshots. Then a person looks at five widths.
4. Return-learning: list every item where the book is silent as a proposed segment and return the list to the book.
