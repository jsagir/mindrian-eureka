# Six-Hat review preparation

**User-facing stage:** Prepare a Six-Hat Decision Review  
**Hire when:** a bounded what-if has evidence-backed arguments from competing perspectives and a human navigator is ready to rule.

`deliberation.prepare_six_hat_review` organizes host-supplied arguments under White, Red, Black, Yellow, Green, and Blue labels, checks which perspectives are missing, and verifies that cited evidence IDs point to supplied source records. It returns the ruling field blank for the human.

This is not the full BONO method. It does not generate personas, conduct the parallel source-research fan-out, run the sequential inter-hat debate, persist arguments into the MindrianOS graph, or write a ruling. A perspective label does not make evidence independent. The LATEST BONO source flow has been inventoried, but its shared MindrianOS graph, egress, human-gate, run-state, and close-loop dependencies are not integrated into this repo. The full capability therefore stays blocked. See [the BONO migration contract](bono-research-debate.md).
